# Node.js Authentication Learning Project

This repository contains my learning and practice implementation of authentication in Node.js.

I created this project while learning how a backend authentication system works, including user registration, login, password hashing, JWT authentication, protected routes, access tokens, refresh tokens, and logout.

The main purpose of this repository is to practice backend development concepts and document my learning progress.

## Topics Covered

* User registration
* User login
* Password hashing using bcrypt
* JWT access tokens
* Refresh tokens
* Authentication middleware
* Protected API routes
* User profile API
* Logout functionality
* Environment variables
* Error handling
* MongoDB database integration

## Tech Stack

* Node.js
* Express.js
* MongoDB
* Prisma or Mongoose
* JSON Web Token
* bcryptjs
* Zod
* Postman

## Learning Purpose

This project is created for educational and practice purposes. It may continue to improve as I learn more about authentication, backend security, validation, and production-ready API development.
